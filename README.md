# Iris Flower Classification

## Project Description

This project uses Machine Learning to classify Iris flowers into three species:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

The model is trained using the Iris dataset and the Decision Tree Classification algorithm.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

## Dataset

The Iris dataset contains 150 flower samples with four features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## Machine Learning Algorithm

Decision Tree Classifier
