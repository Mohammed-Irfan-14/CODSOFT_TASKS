# Titanic Survival Prediction

## CodSoft Data Science Internship - Task 1

This project uses machine learning to predict whether a passenger on the Titanic survived or not.

## Dataset

The Titanic dataset contains information about passengers, including:

- Passenger class
- Sex
- Age
- Number of siblings/spouses
- Number of parents/children
- Fare
- Port of embarkation

## Machine Learning Model

Decision Tree Classifier

## Results

Accuracy: 79.89%
