# Sales Prediction Using Python

## CodSoft Data Science Internship - Task 4

This project uses machine learning to predict product sales based on advertising expenditure.

## Dataset

The dataset contains advertising expenditure for:

- TV
- Radio
- Newspaper

The target variable is:

- Sales

## Machine Learning Model

Linear Regression

## Results

Mean Squared Error: 2.9078

R2 Score: 0.9059

R2 Score: 90.59%

- Python
- Pandas
